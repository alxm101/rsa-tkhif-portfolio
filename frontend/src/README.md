# Rakeen Alam's Portfolio

This is my personal developer portfolio, built as a **Single Page Application (SPA)** with React, React Router, and TailwindCSS.  
It showcases my background, skills, and selected projects as I grow as a backend-focused developer.

---

## 🚀 Features

- **Home Page**: Introduction with personal photo, background, and hobbies.
- **About Page**: Skills, goals, and link to my resume.
- **Projects Page**: Showcases real projects with descriptions and repo links.
- **Contact Page**: Contact information + form.
- **Dark Mode**: Toggle between light and dark themes.
- **404 Page**: User-friendly fallback for broken links.

---

## 🛠️ Tech Stack

- **Framework**: React (Vite)
- **Routing**: React Router
- **Styling**: TailwindCSS
- **Deployment**: Netlify
- **Version Control**: Git & GitHub
